# 入会申请表转 Excel 工具

把《中国民主促进会入会申请表》（.doc / .docx）的内容填入“入会申请表入库信息”Excel 模板，每份申请表生成一个 Excel 文件。全部在本地运行，不联网，不需要安装 Word / WPS。

## 使用方法

1. 双击 `doc2excel.exe`
2. 添加一个或多个申请表文件（.doc / .docx）
3. 选择 Excel 模板（`姓名--入会申请表入库信息.xlsx`）
4. 选择输出文件夹，点击“开始生成”

输出文件名为把模板文件名中的“姓名”替换为申请人姓名，例如 `贾小云--入会申请表入库信息.xlsx`；同名文件已存在时自动加 `(2)`、`(3)`，不会覆盖。模板和输出位置会被记住，下次打开不用重新选择。

处理结果中：
- **⚠ 警告**：需要人工核对的内容，例如取值不在模板下拉选项中、身份证号码无效、职称在字典里找不到
- **· 说明**：程序自动做的转换，例如“无”写为“无党派”、职称换成代码

## 字段对应规则

| 申请表 | Excel 模板 | 处理 |
|---|---|---|
| 姓名、性别、民族、籍贯、出生地、婚姻状况、健康状况、工作单位及职务、职务层次、职级、单位地址、固定电话、家庭地址、邮政编码、手机号码、专业专长 | 同名栏目 | 原样写入，并对照下拉选项检查 |
| 出生年月 | 出生年月 | 身份证有效时取身份证上的出生日期；否则按表内年月写入（日记为 1 日） |
| 参加工作时间、任现职务层次时间、任现职级时间 | 同名栏目 | 写为日期 |
| 身份证号码 | 身份证号码 | 校验 18 位及校验码；表内没填性别时按身份证推算 |
| 党派交叉情况 | 党派交叉情况 | 简称转全称（民盟 → 中国民主同盟，无 → 无党派） |
| 职称 | 职称 | 按“职称字典”换成代码；找不到或有多个同名时原样写入并提示 |
| 学历学位（全日制 / 在职） | 学历学位 | “院校及专业”按最后一个空格拆成学校和专业；学位自动补全为“××学位” |
| 学习与工作经历 | 简历 | 按“自最近经历开始”倒序写入一个单元格 |
| 家庭主要成员 / 主要社会关系 | 同名表格 | “工作单位及职务”按最后一个空格拆成工作单位和职务；政治面貌简称转为下拉选项 |
| 主要成就及获奖情况 | 奖励情况 | 按 ①② / 1. 2. / 换行拆分条目写入“奖励情况”栏 |
| 人大政协 | — | 申请表只有一栏文字，无法拆成模板的结构化表格，有内容时提示人工填写 |
| 电子邮箱 | — | 模板无此栏目，不写入 |

模板栏目位置定义在 `doc2excel/converter.py` 顶部的 `CELL`、`EDU_ROWS` 等常量中，模板版式变化时只需修改这里。

## 开发

开发环境 macOS，需要带 tkinter 的 Python 3.12（Homebrew 的 Python 默认不带，可用 `uv` 安装）：

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements-dev.txt
.venv/bin/python -m pytest -q tests   # 测试
.venv/bin/python app.py               # 运行界面
```

目录结构：

```
app.py                  图形界面（tkinter）
doc2excel/
  doc_reader.py         读取 .doc（直接解析二进制格式）/ .docx，输出表格结构
  form_parser.py        按标签文字从表格中提取申请表字段
  normalize.py          日期、身份证、获奖条目等规范化
  converter.py          写入 Excel 模板，生成警告和说明
tests/                  测试
```

## 打包 Windows 程序

PyInstaller 不能跨平台打包，必须在 Windows 上打包。两种方式：

- **GitHub Actions**：把代码推到 GitHub，在 Actions 页面手动运行 `build-windows`（或推送 `v*` 标签），完成后下载 `doc2excel-windows` 压缩包
- **Windows 电脑**：安装 Python 3.12，双击 `build_windows.bat`，产物在 `dist\doc2excel\`

交付时把整个 `doc2excel` 文件夹压缩发给用户，解压后双击 `doc2excel.exe` 即可，用户电脑无需安装 Python。支持 Windows 10 / 11。
